# Источники изображений

Иллюстрации в `assets/images/words/` сгенерированы для этого проекта по
ассоциативным сценам (Nano Banana, сетки 3×3, затем нарезка). В приложении
используются WebP-файлы; имена соответствуют реестру ассоциаций
`w{wordId}_{variant}_{lemma}.webp`.

- 2664 изображения включены в приложение;
- 4 ассоциации пока используют `assets/images/placeholder.png`
  (`doom`, `furniture`, `glance` — две связи);
- сторонние стоковые изображения и брендинг не используются;
- при публикации рекомендуется зафиксировать дату генерации и checksum
  каждого файла в реестре MediaAsset.
